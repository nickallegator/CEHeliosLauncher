# AG Launcher 2.8.0-test.2

This verification release validates the new in-app update path from `2.8.0-test.1`.

## Changes

- Preserves the complete AG Launcher self-update experience introduced in `2.8.0-test.1`.
- Prevents ordinary CI and local package builds from publishing implicitly.
- Corrects the approval-gated release guard for an absent GitHub release.
- Includes the Pack Studio PostgreSQL JSON-fragment compatibility fix discovered by mandatory integration testing.

Test releases are currently unsigned. Windows may display an unknown-publisher warning during the one-time `2.8.0-test.1` bootstrap installation; stable releases remain blocked until Public Trust signing is configured.
