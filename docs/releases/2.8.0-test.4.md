# AG Launcher 2.8.0-test.4

This update makes launcher release notes readable and keeps their rendering secure.

## Changes

- Converts GitHub's HTML release notes into clean plain text before sending them to the launcher interface.
- Preserves headings, paragraphs, lists, inline text, and common HTML entities without exposing markup.
- Removes active or embedded content, limits the resulting message size, and continues rendering through safe text-only UI APIs.

Test releases are currently unsigned. Stable publication remains blocked until Windows Public Trust signing is configured.
