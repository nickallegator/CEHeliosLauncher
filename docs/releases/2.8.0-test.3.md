# AG Launcher 2.8.0-test.3

This release is the automated publication-path verification target for AG Launcher self-updates.

## Changes

- Uses an explicit GitHub HTTP-status guard before creating an immutable release.
- Fails closed on authentication, network, and unexpected API responses.
- Retains the complete optional in-app update workflow introduced in `2.8.0-test.1`.

Test releases are currently unsigned. Stable publication remains blocked until Windows Public Trust signing is configured.
