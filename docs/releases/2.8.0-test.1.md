# AG Launcher 2.8.0-test.1

This is the final manually installed bootstrap release for AG Launcher self-updates.

- Adds optional in-launcher update checks, downloads, and restart-to-install support.
- Adds an AG-branded update prompt and persistent update controls in Settings.
- Keeps Minecraft launch, Community, and authenticated mod downloads available when update checks fail.
- Adds launcher version/channel identity to authenticated service requests.
- Prepares a disabled-by-default backend minimum-version safety policy.

This test release is unsigned. Windows may continue to show its existing publisher warning until Public Trust signing is enabled for a future stable release.
