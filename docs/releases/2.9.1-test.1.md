# AG Launcher 2.9.1-test.1

This release moves Allegator Games News away from the unavailable legacy host and introduces a schema-versioned publishing platform.

## Changes

- Loads News from the Allegator Games JSON index with RSS fallback.
- Retains a bounded sanitized cache for useful offline reading.
- Supports remotely injected News discovery so the host can change without another launcher or mod build.
- Preserves Home and full News navigation without delaying authentication, Community, or game launching.
- Adds non-blocking News draft automation to launcher and Cobble Power release workflows.

Test releases remain unsigned while Windows Public Trust signing is prepared.
